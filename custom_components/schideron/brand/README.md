# Brand assets

These files are derived from Schideron's official website assets:

- <https://www.schideron.com/images/front/wap/logo.png>
- <https://www.schideron.com/images/front/pc/logo.png>

`logo.png` preserves the official website image. `icon.svg` is a vector
reproduction of the square mark from that official artwork; the PNG icon sizes
are rendered from the vector source.

The Schideron name, logo, and trademarks remain the property of their
respective owner. These brand assets are provided only to identify compatible
products and are not licensed under this repository's MIT license.
